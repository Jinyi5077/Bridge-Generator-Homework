# 成果文件与 ODA 调用说明

本页说明 V0.13 导出文件的用途、制图设置、DXF / DWG 转换及代表性文件的选择。[返回项目首页](../README.md)。

## 成果目录

完整运行的目录结构如下。复核编号随每次运行变化，主跨和车道改变时内容也随实际输入改变。

```text

├─ 02_桥梁工程课程设计计算书.pdf
├─ 03_设计汇报.pptx
├─ 输入参数.json
├─ 输入与来源.json
├─ 规范配置.json
├─ 工况与组合.json
├─ 计算记录.json
├─ 计算追溯表.csv

├─ 设计结果.json
├─ 计算范围说明.txt
├─ 制图检查.json
├─ 生成清单.json
├─ CAD_DXF/                  三张原始 DXF
├─ CAD_DWG/                  三张转换后的 DWG
├─ CAD_回转检查/             DWG 再转回的 DXF
├─ CAD_PDF/                  三张实际 CAD 布局 PDF

```

`生成清单.json` 保存完整运行的文件字节数与 SHA-256，不能用它代表仅挑选了一部分文件的目录。本仓库另有 `代表文件清单.json`，记录选中文件、原始位置与哈希，并保留完整运行清单用于追溯。

## 计算书

DOCX 与 PDF 按课程计算路径组织：任务与输入、几何、恒载与活载、组合、内力、预应力、施工阶段、普通钢筋和具名验算、敏感性分析，以及第 11 章独立复核。

只写实际计算的内容。课程之外的空间、局部和下部结构只说明范围，不写成已完成的验算章节。

DOCX 字体字段为中文宋体、拉丁字母 Times New Roman；公式保存为 `Equation.DSMT4` 的 MathType OLE 对象，包含预览图。PDF 使用独立排版与公式预览，并不是 Word 文档的直接转换。因此，PDF 的分页检查不能代替 DOCX 在 Word 中的分页检查。

发行及本次检查区分字体 / OLE / 内容结构与实际渲染。V0.13 算例同时遴选 DOCX 和 PDF。DOCX 的 63 个 MathType OLE 与字体元数据已核对；未将未独立渲染的 Word 排版宣称为已验证。

## 汇报 PPTX

程序生成 23 页答辩汇报，以实际设计结果填入表格、控制值与验算状态。图表采用 PowerPoint 原生对象并附数据工作簿，表格与文字可编辑；演讲备注记录来源和讲解重点。

结论页包含真实的独立复核状态与来源编号。独立复核出现失败时不会将 PPT 结论固定写为通过。

## CAD 图纸

### 三张图的内容

| 图纸 | 代表内容 |
| --- | --- |
| 总体立面图 | 立面与平面、跨径尺寸链、支点与剖切标记、变高度箱梁轮廓、桥宽和图框 |
| 跨中横断面图 | 实际车道与幅数、顶板悬臂、板厚、腹板、箱室和倒角、尺寸分组及构造详图 |
| 墩顶横断面图 | 墩顶加高加厚截面、加腋与倒角、对应尺寸及构造详图 |

下部结构在图纸中属于示意定位，不能据此理解为完成墩台和基础设计。等效钢束与普通钢筋信息属于课程方案，不能直接替代施工图级分束和钢筋详图。

### 图幅、单位和字体

采用 A3 横向图幅，纸空间 420×297 mm，纸空间比例 1:1，视图由视口采用各自比例。模型以毫米为单位；可编辑尺寸使用原生 `DIMENSION`，测量真实几何长度，尺寸文字不覆写为固定数值。

中文样式 `CN_FS` 引用 `simfang.ttf`，字宽系数 0.7；数字与尺寸样式 `ISO_NUM` 引用 `isocpeur.ttf`。图纸中文字高与标注间距以纸面尺度组织，尺寸样式随模型比例调整。接收方 CAD 阅读器需要能解析相应字体或配置替代字体；本仓库不分发商业字体文件。

CAD 字体与计算书宋体 / Times New Roman 要求分开配置。程序采用的是参考工程制图风格，尺寸和字体检查不等同于完整标准条文审查。

### 线宽与线型

图层线宽为 DXF 原生 lineweight，打印开启线宽。主要设置如下：

| 图层 / 内容 | 纸面线宽 |
| --- | --- |
| `B-CUT` 剖切、`P-FRAME` 图框 | 0.50 mm |
| `B-OUTLINE` 轮廓、`B-PIER` 示意、预应力和钢筋 | 0.25 mm |
| 细部、中心线、隐线、剖面线、尺寸、文字与图框细格 | 0.13 mm |

中心线和隐线使用分别设置的线型。剖面线保留空腔边界，避免将箱室填满。CAD PDF 从实际纸空间布局渲染，保留图框、视口、字体与尺寸关系。

实现：[drafting.py](../src/bridgegen/cadlite/drafting.py)、[sheets.py](../src/bridgegen/cadlite/sheets.py)。此前用户提供的工程图框和倒角箱梁图用于理解版式与构造表达，本仓库只上传程序自己的输出，不上传那些原始工程文件。

## ODA File Converter

### 它在程序中负责什么

[ODA File Converter 官方页面](https://www.opendesign.com/guestfiles/oda_file_converter)说明其具备图形和命令行接口，可以在 DXF 与 DWG 及不同版本间转换。[ezdxf 的 ODA 支持文档](https://ezdxf.readthedocs.io/en/stable/addons/odafc.html)也说明了调用已安装转换器的方式。

本程序用 `ezdxf` 构造 DXF，再用 `subprocess` 调用外部 ODA；没有直接用 `ezdxf` 写 DWG，也不需要通过 AutoCAD COM 自动化。

```mermaid
flowchart LR
    A[参数与几何] --> B[ezdxf 原生 DXF]
    B --> C[ODA 命令行]
    C --> D[ACAD2018 DWG]
    D --> E[ODA 回转 DXF]
    E --> F[语义比较与 DXF audit]
    F --> G[最终 CAD PDF 与 PNG]
```

### 查找与配置

查找顺序依实际代码为：

1. 输入中明确指定的 `oda_path`。
2. 环境变量 `ODA_FILE_CONVERTER`。
3. PATH 中的 `ODAFileConverter`。
4. 程序附近的 `tools/oda` 及常见安装目录，包括本机的 `D:/APPS/ODA`。

明确路径必须指向已存在、名称正确的转换器可执行文件。示例配置：

```json
{
  "oda_path": "D:\\APPS\\ODA\\ODAFileConverter.exe"
}
```

或者在 PowerShell 中设置：

```powershell
$env:ODA_FILE_CONVERTER = 'D:\APPS\ODA\ODAFileConverter.exe'
```

本次运行使用本机已安装的 ODA 27.1.0.0；这不是对下载页面当前版本的指定要求。

### 实际调用

转换在隔离临时目录中执行，临时文件使用 ASCII 名称，成功后恢复中文成果名。核心参数为：

```python
subprocess.run([
    oda_exe,
    input_directory,
    output_directory,
    "ACAD2018",
    "DWG",
    "0",       # 不递归
    "1",       # 加载时 audit
    "*.dxf",
], capture_output=True, timeout=180)
```

再用相同接口将 DWG 转回 DXF。Windows 下转换子进程隐藏窗口。程序包没有将 ODA 安装文件、许可或字体捆绑再分发；接收方需要自行安装 ODA 才能生成 DWG。

### 转换后检查

检查输出文件存在与大小、DWG `AC1032` 版本标识、回转 DXF 的 audit，以及前后 CAD 语义：

- 模型单位。
- 原生尺寸数量、测量值与尺寸样式；拒绝固定尺寸文字。
- 中文与数字字体文件名、字宽、文字内容与字高。
- 图层线宽、线型和打印属性。
- 中心线、隐线的间隔。
- 图幅、纸空间打印比例、视口比例。
- 剖面空腔边界和实体类型数量。

这些检查用于发现转换是否损坏制图语义；它们不独立证明结构几何设计正确，也不等于对每个 CAD 坐标作全面工程审查。

如果没有 ODA，程序保留完整 DXF 和其他成果，并报告未生成 DWG。转换失败时保存明确状态；不能仅因已有旧 DWG 而视为成功。

实现：[oda.py](../src/bridgegen/cadlite/oda.py)。

## 为什么选这些代表性文件

本仓库选择能覆盖“看懂方案、查看计算、继续编辑、追溯结果、检查转换”的文件：

| 类别 | 所选文件 | 目的 |
| --- | --- | --- |
| 计算 | DOCX / PDF 计算书 | 阅读已计算的章节、公式、控制值与复核结论 |
| 汇报 | 原始 PPTX | 查看可编辑图表、数据工作簿及来源备注 |
| 制图 | 三张 DWG、DXF 与 CAD PDF | 同时提供编辑、交换和直接预览格式 |
| 可视化 | 三张 CAD PNG、五张主要图表 | 仓库首页直接展示实际成果 |
| 追溯 | 输入、设计结果、计算数据与追溯 CSV、计算记录 | 复现参数和查看数值来源 |
| 复核 | HTML / JSON 报告、独立输入 / 输出 | 查看双程序数值、容差和独立计算证据 |
| 校验 | 制图检查、原始生成清单与代表文件清单 | 核对选中文件来自该次完整运行 |

未重复上传主结果快照、中间公式 PNG、临时 PPT 或其他历史运行目录。选中文件保持原始字节，不手工改写控制值与验算状态。[具体文件与本次结果](../samples/132-220-132m-3lanes/README.md)。
