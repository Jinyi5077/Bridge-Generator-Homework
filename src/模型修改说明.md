# v0.11 模型变更与核实记录

## 范围与信息

主跨范围为50–150 m，保留2/4/6总车道；边主跨比0.5–0.8，边跨范围25–120 m。默认最大候选主跨150 m。

姓名、学号、学校、班级、指导教师、制图日期作为输入元数据保存并审计。模型分析允许空值，UI/API生成入口负责必填姓名和学号。单行字符长度上限依次为16/32/44/24/28/10。

相对高程是默认模式；绝对高程必须在输入中明确提供deck_elevation。基准点为全桥长度中点的结构顶板横向中心线。纵坡范围±0.06，高程允许-1000至10000 m，均为用户输入范围。未推导地形、设计水位或现场高程。高程与纵坡仅用于制图定位；纵向梁模型仍采用跨度水平投影。

## JTG D60—2015边界

核实来源：交通运输部官方《公路桥涵设计通用规范》及旧工作区的原规范扫描页面：

- JTGD60_30.png：印刷第26页，第4.3.1条，公路Ⅰ级均布荷载10.5 kN/m，剪力集中荷载乘1.2。
- JTGD60_31.png：印刷第27页，表4.3.1-2，计算跨径L0≥50 m时集中荷载360 kN；同页第8款规定计算跨径大于150 m才考虑纵向折减。
- JTGD60_32.png：印刷第28页，表4.3.1-6首档为150<L0<400 m，系数0.97；连续结构按最大计算跨径确定，不按全桥总长。

因此50–150 m范围内，qk=10.5 kN/m、Pk=360 kN、纵向系数1.0保持原值；150 m本身不应使用0.97。

官方地址：https://xxgk.mot.gov.cn/jigou/glj/202006/P020240327350422059754.pdf

## 新跨度初选

对新增>120 m区间，未明确输入的板厚、腹板、倒角/加腋尺寸按已有跨度初选公式匹配。每幅两道箍筋初选18 mm，每幅三道20 mm。均为可编辑课程设计起始值，不是规范系数。显式输入保留，验算限值保持原值。

旧初选150 m三种车道均出现真实抗剪不通过，证据保存在model_150_legacy_initials。调整构造初选后，2/4道桥台端出现抗裂不通过，证据保存在model_150_pre_anchor_fix。

## 桥台端等效钢束偏心修正

原等效布束在零外荷载弯矩端部仍选接近最大下偏心。150 m两道单幅初选的端部e=2.20924 m超过实际截面核心上界1.27071 m，导致预应力本身使顶缘产生拉应力。

自动端部初选采用线弹性偏心压力公式：

```
σ_top = P/A - P*e/Wt
σ_bottom = P/A + P*e/Wb
-Wb/A <= e_end <= Wt/A
```

同时满足保护层几何限制，仅调整A0/A3端部偏心。其余布束初选、损失计算和正常使用限值未改。新增prestress_end_eccentricity_m默认null自动，显式数值只检查保护层并原值参与计算。

规则、截面核心边界、原端部偏心和最终偏心写入prestress.end_anchor_rule，计算记录P_END_KERN及计算过程追踪。修正150 m两道案例最大边缘拉应力由1.45983降至0.81113 MPa，允许值仍为1.325 MPa。

## 已验证

150 m×2/4/6道均真实计算，最终课程范围内6项具名验算通过；最大力平衡误差1.320×10^-6 kN。完整结果在model_150_matrix。

显式旧箍筋可产生抗剪FAIL，显式桥台端e=2.2 m可产生抗裂FAIL，程序均保留真实失败状态。课程范围之外的空间、局部、锚固区和下部结构承载力仍未验算。
