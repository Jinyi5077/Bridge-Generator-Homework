# V0.12 内置交叉验证修改说明

日期：2026年10月6日。

## 已实现的功能

1. `crosscheck/` 为独立计算包；计算内核不导入主引擎。单独进程运行并检查主引擎模块未加载。
2. 独立重建单箱单室倒角截面，以水平条带积分求面积、形心、惯性矩、截面模量、剪切第一矩及压区面积。
3. 独立计算一期与二期恒载、移动汽车荷载、四类组合、支反力、位移、基频及冲击。
4. 固定最终钢束与钢筋方案，复算简化损失、主次效应、截面应力、抗弯、抗剪、抗裂、压应力、挠度及双主墩静定悬臂阶段。
5. 自动解析算例自检、独立网格收敛、平衡与支点协调检查，分开记录数值、规则、方案、执行及覆盖状态。
6. 主计算结束后自动复核；UI 提供本次固定方案的重新复核按钮。计算书增加第11章；23页PPT的结论页及备注包含实际复核结论。
7. 离线 HTML 与 JSON 双值报告、主结果快照、输入/结果/源码哈希，及命令行旧成果复核入口。

## 本轮纠正的主程序计算路径

| 问题 | 修改 |
| --- | --- |
| 钢束转角由偏心距求导 | 由钢束相对固定截面基准的实际深度求导；损失与抗剪使用同一设计节点 |
| 抗剪把钢束竖向分量一律视为有利 | 对正、负剪力分支分别扣除有符号分量，再取不利值；报告列出净需求与Vcs |
| 横坡截面钢束深度重复叠加上缘坐标 | 承载力计算直接使用实际深度，消除重复偏移 |
| 零承载力时除法结果变成零利用率 | 正需求且零承载力明确判为极大利用率，不会通过 |
| 普通钢筋选择忽略压区高度 | 选择和终止均检查压区高度；加筋不能修复超深压区 |
| 挠度采用含冲击活载 | 采用不含冲击的频遇汽车荷载、长期系数及0.95EcI0；反拱单独用EcI0及2.0长期系数 |
| 变截面刚度和自重仅取单元中点 | 四点Gauss沿单元积分，并加密默认网格、细化线性求解残差 |
| 平滑与钢束截断距离依赖计算网格 | 方案设计节点与分析网格分开，保持原约2m设计节点的物理尺度 |
| 铰接端数值微小弯矩改变锚固方案 | 方案选择时按铰接端真实零弯矩处理，不以舍入误差选正负弯矩区域 |
| 全预应力零允许拉应力导致汇报除零 | 零拉应力通过时利用率为0；有拉应力时记录未定义利用率并保留失败 |

## 验证范围与限制

独立复核目标是课程纵向模型及固定方案。它不是完整工程设计复核，数值一致也不能证明两套程序共有的规范理解必然正确。

移动荷载使用分段Gauss积分、切点两侧极限位置和逐级加密的离散搜索；收敛结果与实际容差同时输出。预应力使用最终等效合力方案，尚未细化真实分束、锚固区和逐龄期耦合；悬臂复核未继承合龙锁定与施工全过程。因此报告持续标记覆盖为PARTIAL。

120m及150m六车道的默认初选抗剪失败是本轮真实检出项，不作为程序执行失败，也不通过调宽数值容差掩盖。相关旧回归用例的“所有初选必然通过”预期已依据独立复算修正为保留抗剪失败。
